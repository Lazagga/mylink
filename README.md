# myLink

TypeScript와 Next.js App Router로 만든 반응형 링크 모음 데모입니다. `DESIGN.md`의 타이포그래피, 색상, 여백 및 카드 원칙을 참고했습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 배포용 빌드는 `npm run build`, 타입 검사는 `npm run typecheck`로 확인합니다.

## 링크 수정

`src/app/page.tsx`의 `links` 배열과 프로필 문구를 원하는 내용으로 바꾸세요. 현재 링크는 모두 `example.com`을 사용하는 예시 데이터입니다.
